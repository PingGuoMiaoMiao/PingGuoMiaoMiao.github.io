# 使用 Vite 官方模板创建项目

```bash
# 使用 Vite 官方模板创建项目
npm create vite@latest seckill-admin -- --template vue

cd seckill-admin
npm install

# 安装 Element Plus 和自动导入插件
npm install element-plus @element-plus/icons-vue

# 安装按需导入插件（关键！减少打包体积）
npm install -D unplugin-vue-components unplugin-auto-import
```
